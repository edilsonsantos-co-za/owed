## Description

Owed is an AI collections copilot for freelancers and small studios who bill through PayPal. Claude agents read your invoices, learn how each client really pays, and draft the right reminder. Nothing is sent until you approve it.

My entry for the PayPal AI Hackathon 2026.

▶ Try it: https://owed.edilsonsantos.co.za

Built with
• PayPal Invoicing v2, Transaction Search and the PayPal Agent Toolkit
• Claude (Anthropic API) for the agents and the morning brief
• AG Studio and its Agent Framework, with a custom Claude adapter and collections agent
• Next.js, React, TypeScript, Tailwind CSS
